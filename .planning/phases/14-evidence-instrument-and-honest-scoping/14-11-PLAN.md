<objective>
Close the root cause of Phase 14's one recorded gap (14-VERIFICATION.md Gap 1) by
making the corpus-wide run record incapable of reporting a result it did not
actually finish producing, and by removing the substring-matching cost hazard
that pushed it against its own ceiling.

This is WR-01 (stale, measurably false timeout doc comment plus a budget with no
real margin) and WR-02 (the `-run` self-recursion fix applied to two markdown
cells by hand instead of to the code that builds consolidated patterns) from
`14-REVIEW.md`. Both are prerequisites for plan 14-12's exemption removal: a
retry without them reproduces plan 14-10's 300.11s near-miss and its nine
spurious "declared EXERCISED exceeds ceiling WIRED" failures.

Purpose: an instrument that times out mid-batch currently degrades silently into
a lower grade ceiling. That is the phase's own named failure mode, one level up —
a guard whose red/green outcome is produced by something other than the claim it
grades.

Output: a completion-witnessed run record, a measured-and-asserted timing budget,
an anchored producer/consumer name contract, and three new seeded-fault proofs.

Closes: EVD-02 (the run-record substrate the corpus-wide bar depends on).
</objective>
