<objective>
Close DX-08: make structurally different defective programs produce
distinguishable diagnostics, by attaching the discarded error-recovery extent to
the diagnostic as a `skipped_region` cause, and ship the distinctness gate in the
same plan.

Both the fix and the `diagnostic_distinctness` gate ship in this one plan (D-14-33):
pinning the collision as a failing control and deferring the fix would be the
right answer if the fix cost a schema bump or churned the pinned-ID corpus, and
it does neither.

Purpose: today three structurally distinct broken programs mint **one** `result:`
ID, so an evidence cache keyed on that ID would serve one program's evidence for
another — evidence confusion in a project whose product is evidence (D-14-43).
The counter-argument the reviewer will raise first, and which the plan must
answer, is "the first diagnostic is just one token late, move the span": it is
not late, and moving it does not separate the three programs, because all three
share the offending token at the same offset (D-14-34).

Output: a ~14-line parser change, a lexer-only corpus predicate, a three-assertion
gate, a frozen collision control, and an enumerated published-ID churn table.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.lang` source bytes → parser | Untrusted-shaped input in the general case; here repository fixtures, but the recovery path is the one reached by arbitrary broken input |
| diagnostic content → published identity hash | Cause content now feeds the identity hash; a content change moves a published ID |
| frozen capture → gate | The capture is the gate's only non-inertness evidence and must be read-only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-07 | Spoofing | `result:` identity | high | mitigate | Attach the discarded recovery extent as an identity-bearing cause so three distinct sources no longer mint one result ID; asserted by `TestDiagnosticDistinctnessIsOne` (Task 3) |
| T-14-08 | Tampering | published diagnostic IDs | high | mitigate | Before/after enumeration over every `testdata/**/*.lang` with an exact predicted diff set; any unpredicted fixture fails the task (Task 2) |
| T-14-09 | Tampering | frozen collision control | high | mitigate | Capture taken before the fix, read-only in the gate, no regeneration path, working-tree cleanliness asserted (Tasks 1 and 3) |
