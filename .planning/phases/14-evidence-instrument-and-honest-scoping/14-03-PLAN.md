<objective>
Close DX-09: an `unrepairable` verdict explains itself. The information is already
in hand at the decline site and is thrown away — `selectRepair` returns an empty
code when its loop finds no driver-eligible repair. Make the decline carry the
first diagnostic's code in document order, the full ordered code list, a coded
decline reason, and the best applicability observed.

Purpose: an editing agent that receives `unrepairable` with an empty diagnosis
gets no signal at all about *why*. Honest declines stay honest and stay
`unrepairable` — they simply now state their reason in the protocol rather than
leaving it as silence.

Output: three additive `omitempty` fields on `Outcome`, three new decline
constants, a widened `selectRepair`, a guard over the whole capture corpus, and
its non-inertness proof.
</objective>
