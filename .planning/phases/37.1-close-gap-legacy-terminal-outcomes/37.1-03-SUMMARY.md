## Decisions Made

The reason-byte rule stays narrow: reject malformed UTF-8 inside defect reasons while keeping valid controls, NUL, U+FFFD, and literal escape-looking bytes. The core check runs before JSON cloning so the independent boundary sees original bytes.

The route census is the sole old-state oracle for later additive C changes. It retains the previous Adler projection explicitly and makes future deltas identify one unique byte anchor and exact source/core/C bindings.
