<objective>
Build the Phase 5 half of the milestone corpus: a hand-written adversarial subset
whose every member is engineered to trigger one NAMED `-O3`/LTO transformation,
plus a bounded enumerated closure over the current grammar with its bound pinned
as a versioned constant.

Purpose: a green `-O0` vs `-O3` differential over today's corpus proves close to
nothing (D-05-24). Every current corpus program's only observable effect crosses
a cross-TU boundary that is opaque to the optimizer without `-flto`, so the
existing differential is green by construction, not by evidence. Real evidence
needs programs the optimizer can actually perturb — that is what part (a) is —
and a scope statement that is asserted in code rather than described in prose —
that is what part (b)'s bound is.

Output: six hand-written adversarial programs, a bounded core enumerator, and a
versioned bound constant that `scripts/verify-phase5.sh` will duplicate.
</objective>
