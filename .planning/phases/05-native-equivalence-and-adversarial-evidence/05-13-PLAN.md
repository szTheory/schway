<objective>
Make the coordinated source-to-core false claim DEMONSTRABLE rather than merely
asserted: build an adversarial program whose source and core artifacts agree on a
false claim, prove the gate passes it, and attribute that pass to a distinct
named escape.

Purpose: D-04-31 item 1 currently records this escape in prose. Prose decays.
D-05-30's decisive addition is an adversarial program that ACTUALLY constructs
matching-but-false source/core artifacts and is asserted to pass the gate as a
named escape — demonstrating reachability is the only thing that distinguishes
this from the prose-only version. This is strictly better evidence, and it is
explicitly not a closure: demonstrating an escape is not closing it.

Output: the adversarial artifact pair, the escape constant, and the
declared-but-never-detected assertions.
</objective>
