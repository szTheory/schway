| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| pre-fix baseline -> post-fix comparison | the conformance golden is the only whole-corpus evidence that loop-free conformance C keeps its bytes; it must come from the pre-fix revision | conformance C hashes |

| generated C process -> native runner | exit status and stderr bytes from an untrusted child process become a named verdict | exit status, stderr |

| emitter change -> existing goldens | byte drift outside the one gated line would silently change evidence | generated C |
| guide commands -> working tree | following the guide must not leave untracked files that make receipts fail | build outputs |
| test -> git subprocess | the docs test spawns git and must stay bounded and read-only | paths |
| local branch -> public origin / hosted CI | push and dispatch are outward-facing; human-authorized only | commits, workflow dispatch |
| hosted run record -> evidence prose | claims must match what was observed | run IDs, job conclusions, SHAs |
| planning docs -> hosted meta-tests | a malformed planning doc can fail the hosted run | planning markdown |
