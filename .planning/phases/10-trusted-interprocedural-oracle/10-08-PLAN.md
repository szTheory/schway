## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| four independent derivers → one comparison harness | The harness must only COMPARE, never compute the fact a second way — it is a verification-tier consumer, not a fifth deriver |
| a declared divergence → the debt register | An allowlist entry crosses from "known problem" to "invisible problem" if it names nothing |
| a seeded fault → its package boundary | A fault reachable from outside its package would prove nothing about independence |
