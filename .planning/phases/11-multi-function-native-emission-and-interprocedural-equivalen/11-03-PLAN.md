<objective>
The tracer slice: make the thinnest possible multi-function Lang program
executable end to end. One entry point is wired through every layer this phase
touches — `callgraph` resolves the entry, `cgen`'s new whole-program assembler
emits the C17 translation unit with one shared `emitCall` helper, `session`'s run
sites drive the same resolved entry into both the interpreter and the binary —
and the two engines are shown to agree at `-O0`.

Purpose: this proves the multi-function architecture end to end on one path
before any expansion work is committed. A dead end here is found after one
commit, not after ten layers.

Output: `callgraph.EntryFunction`, `cgen.emitProgram`, `cgen.emitCall`, the
switched `session` run sites, and a `testdata/phase11/` corpus whose thinnest
member runs identically on both engines.
</objective>

<assumption_delta_decision>
The `assumption-delta` detector fired (`kind: pluralization`) on this phase's
scope. The genuine delta is real and is this phase's whole subject: the compiler's
unit of emission changes from **the function** to **the program**.

- **Primary noun (generalized identity):** `core.Program`, with its entry resolved
  by `callgraph.EntryFunction`. The function is now a detail of the program.
- **Decision:** `promote`. `EntryFunction(program)` becomes the single primary way
  every consumer answers "which function IS this program", and `Functions[0]` is
  demoted to the N=1 special case it always was. This is deliberately NOT
  add-alongside: leaving `Functions[0]` as a co-equal path is exactly how the
  oracle and the binary come to disagree about which function they ran.
- **Accepted debt:** the six single-function whole-TU emitters DO remain alongside
  the new `emitProgram` (D-11-01), but that is an emitter-body coexistence, not a
  second identity model — they are reached only through the same promoted
  dispatch. What would force their deletion is Q-05's N=1 convergence
  differential, tracked as D-11-02 in `PHASE-11-DEBT.md`.
- **Invariant test (adopted):** Task 2 adds an assertion that no production file in
  `session` resolves an entry function by indexing `Functions[0]`; it goes red the
  instant a future phase reintroduces the singular assumption.
</assumption_delta_decision>
