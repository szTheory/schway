`rootFileSystem` implements `fileSystem` over `*os.Root`:

- `Open` delegates to `Root.Open`, returning a `moduleFile` interface with `Stat` and `Read`.
- `ListDir` opens the directory through the root and calls `ReadDir(256)` in a loop. It stops after `max` entries and reports `truncated` when more exist, so the listing is never unbounded (no negative-count read).

`validateModulePath(module)` (per D-07 and D-18):
- splits on `.`;
- requires at least one segment;
- requires each segment to be 1..64 bytes, ASCII, and to match `[a-z][a-z0-9]*(_[a-z0-9]+)*`.

Hand-write the matcher: a byte loop, with no regexp and no unicode tables.

`resolver.read(module, importer, at)` produces one diagnostic per refusal. Each has primary span `at` (the import declaration in the importer), is built with `diagnostic.Error(code, at, message)`, and is then given `InUnit(importer)`. The message names the module and the root-relative path, never an absolute path. The steps run in order:
1. If `validateModulePath` fails, return `module.invalid_segment`.
2. Build the root-relative components per D-05: each directory segment, then the final segment plus `.schway`.
3. For each component prefix, `Lstat` it:
   - `fs.ErrNotExist` goes to the case/not-found check;
   - a symlink is `module.symlink`;
   - a non-directory intermediate is `module.not_found`;
   - any other error is `module.escape`.
4. For each component, run `ListDir(parent, MaxDirectoryEntries)`:
   - a truncated listing is `module.directory_limit` (D-24);
   - no byte-equal name and an EqualFold match is `module.case_mismatch`;
   - neither is `module.not_found`.
5. If the final Lstat mode is not regular, return `module.not_regular`. This happens before any Open.
6. `Open`, then `Stat`. If `!os.SameFile(lstatInfo, statInfo)`, return `module.unstable_file`. An Open error after the pre-checks is `module.escape`.
7. Read with `io.ReadAll(io.LimitReader(f, MaxSourceBytes+1))`. If the result is longer than `syntax.MaxSourceBytes`, return `diagnostic.Error("syntax.input_limit", at, ...).InUnit(module)`, per D-13 with Unit naming the file. A read error is `module.read_failed`.
8. Return `Source{Module, RelPath: slash-joined components, Bytes}`.
