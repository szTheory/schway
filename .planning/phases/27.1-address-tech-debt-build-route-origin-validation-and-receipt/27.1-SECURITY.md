## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| source file -> session application routes | untrusted `.schway` bytes enter BuildApplication, RunInterpreterApplication, VerifyApplicationCases | program source |
| session -> filesystem / clang process | build writes an artifact and sidecar and spawns clang only after admission | generated C, native artifact |
| session API -> CLI JSON | refusal status/code becomes a public protocol result | refusal codes, exit classes |
| receipt log files -> gate script | downloaded or committed logs are parsed by POSIX sh | receipt text |
| guide text -> developer / test | the guide is command truth (D-27-06); the test executes text extracted from it | shell command line |
| local branch -> public origin / hosted CI | push and dispatch are outward-facing; human-authorized only | commits, workflow dispatch |
| hosted artifact download -> local repo | downloaded logs are untrusted data until gated | receipt artifacts |
| evidence prose -> future readers | claims must match what was observed | run IDs, SHAs, claims |
