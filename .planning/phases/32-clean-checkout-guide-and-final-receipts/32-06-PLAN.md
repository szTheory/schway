## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hosted runner -> receipt log | the log is produced on a runner and uploaded as an artifact |
| receipt logs -> gate | the gate decides whether two logs form an accepted receipt |
| local tree -> freeze | any later code change would silently invalidate the receipts |

| T-32-18 | Spoofing | forged log | medium | accept | Consistency-only gate (stated in its header, and deferred by CONTEXT). Authenticity comes from the hosted run ID and artifact. |
