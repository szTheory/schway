<objective>
Widen the interpreter's fixture-route defect predicate so every abort-like defect with a live fixture owner yields a defect Execution matching native's exit 65 and stderr, restoring differential parity (29 WR-03; D-09 refined by D-25).

Purpose: today only the byte-index OOB defect is accepted; overflow, remainder-by-zero and user `defect` with a live owner become a hard interpreter error while native aborts with exit 65. That is a false differential disagreement.

Output: a reworked predicate, a white-box predicate test, flipped session subtests, and a native parity test.
</objective>
