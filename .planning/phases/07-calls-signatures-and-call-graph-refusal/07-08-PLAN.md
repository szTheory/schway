<objective>
Stage 0's deferred half, landing last by construction. Complete `ClosureDigest`
as the Merkle chain over callee summary digests (D-07-12), computed in
`callgraph.Order`'s reverse postorder over a graph that `07-06` and `07-07` have
already proven acyclic.

Purpose: **D-07-38.** The chain terminates only on a DAG. The superseded plan set
chained callee digests in `07-02` while cycle detection did not arrive until
`07-04`, so a cyclic program could reach a non-terminating digest computation
before the gate that would have refused it existed. Reordering is the entire fix,
and it is why this is the last plan in the phase rather than part of `07-01`.

There is also a dividend: **D-07-18** chose the three-color DFS partly because
*"the reverse postorder is exactly the ordering Phase 08's summary fixpoint needs
on an accepted graph — also free"*. The digest chain needs that same ordering, so
`callgraph.Order`'s existing return value is consumed rather than a second
traversal being written.

Output: the chaining arm on `07-01`'s canonical preimage; the
callee-changes-invalidates-caller regression that is the whole point of the chain;
the peer's independent re-derivation of the chained digest; and the seeded
mutation that proves the control is real.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| call graph -> digest computation | the chain terminates only on a DAG; the acyclicity proof is a precondition, not an assumption |
| callee summary -> caller digest | a chain over callee **summary** digests; a callee body must never be reachable from here |
| digest -> staleness verdict | consumers treat a matching digest as "not stale"; they must never treat it as "not forged" |
