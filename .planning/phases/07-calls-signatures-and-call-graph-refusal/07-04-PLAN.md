Iterative three-color (white / gray / black) DFS over an **explicit stack**, roots
= **all declared functions**, not just the entry point. Native Go recursion is
prohibited — the compile-time traversal must cost no Go stack.

The distinguisher is **on-stack (gray) re-entry**. A node already black is a
legitimately revisited shared node in an acyclic subgraph, not a cycle. Swapping
the gray check for a plain visited set is the highest-value seeded mutation this
phase must kill (07-05), so keep the two states genuinely distinct in the code.

Build edges by enumerating operations with `Kind == core.OpCall` **across all
blocks**, never by block position (D-07-28). **Dedupe edges at graph-build time**
so `E` is bounded by `V²` rather than by operation count; traversal stays `O(V+E)`.

function shadowing a foreign symbol cannot silently drop an edge. An edge whose
callee resolves to nothing must **refuse**, never be dropped — a dropped edge is
how a cycle escapes.

so the diagnostic's ordered `Causes` can be built without re-deriving, with
`Error() string`, `Code() string` returning `"core.call_graph_cycle"`, and an
exported `CycleError(err error) (*cycleError, bool)` accessor.
