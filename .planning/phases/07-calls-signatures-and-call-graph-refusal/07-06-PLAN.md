<objective>
Stage 2a. Create `internal/compiler/callgraph` — an iterative three-color DFS over
an explicit stack, roots = all declared functions, edges = `CalleeID` — wire it
into `check` so a program whose calls form a cycle is refused by name before
`check` returns, give the refusal a deterministic published identity, and
mutation-kill the two controls that matter.

Purpose: SEM-07's *"never a hang"* is a structural claim, not a timeout. The
distinguisher is **on-stack (gray) re-entry**, never depth or visit count. The
reviews rated the algorithm choice sound but its inputs absent — `CalleeID`
(landed in `07-03`) and a span story (D-07-35) both now exist, and rotation alone
was shown not to make witness selection deterministic (D-07-43).

Output: the `callgraph` package with a witness-carrying typed error; a
canonically-rotated, deterministically-selected, bounded `core.call_graph_cycle`
diagnostic; cycle refusal live in `check`; the diamond/shared-leaf corpus without
which the highest-value mutation cannot be killed; and both mutation kills.

**Ordering note (D-07-38):** this plan and `07-07` must land **before** `07-08`'s
closure-digest chaining. The digest chain terminates only on a DAG, so acyclicity
is proven first.
</objective>

callee ID (Task 1 did the adjacency half). Collect the candidate witness for each
cycle discovered and select the one whose **canonical rotation is
lexicographically smallest**. Rotation alone normalizes a single witness; it does
not choose between several, which is precisely the gap codex identified.

**Rotation (D-07-16).** Canonically rotate the selected cycle's member list so the
**lexicographically smallest function ID sits at index 0** before constructing
`Causes`. Without rotation the same cycle yields a different `Diagnostic.ID` per
discovery start order — an unstable versioned API, because `Causes` participates
in ID identity verbatim and in order (`diagnostic.go:96-117`).

**Span projection (D-07-35).** `callgraph.Order` and `cycleError` carry
**operation IDs**, never spans. `check` projects an operation ID to a span through
its own in-memory emission bookkeeping when it builds the diagnostic. **No `Span`

core artifact, against D-07-08's whole point. The `corevalidate` peer (`07-07`)
has no spans and needs none; its job is refusal, not diagnostics.

`pathoracle.MaxPaths`'s pattern: the reachable maximum today, why the constant
sits where it does, that it is fail-closed, and that it is never raised to make a
test pass.

`cycle_member` causes. `Order` still visits every node and edge; a deep acyclic
graph is legal and unbounded (**D-07-17**: call-graph depth is unbounded provided
the graph is acyclic, and no maximum depth is declared this phase — a static
ceiling would false-positive on exactly the parser-shaped programs spike S-007

checkpoint.
