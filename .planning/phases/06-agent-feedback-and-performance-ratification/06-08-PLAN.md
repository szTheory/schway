## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| spawned `clang` / platform probe -> `ProbeMachine` | Untrusted, potentially unbounded subprocess output |
| host environment -> `MachineFacts` | The privacy seam: what about this host is allowed into a published identifier |
| raw timing samples -> gate verdict | The honesty seam: a fabricated percentile would become a ratified budget |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-MEASURE-01 | Information Disclosure | host fingerprint in `machine_id` | high | mitigate | Six declared facts only; `TestMachineIDExcludesHostFingerprints` asserts both the absence of fingerprint APIs in source and the absence of hostname/username/home-path substrings in the marshalled facts |
| T-06-MEASURE-02 | Denial of Service | unbounded probe stdout/stderr | high | mitigate | Reuse the shipped 64 KiB-plus-one bounded writer and 5-second deadline; typed truncation and timeout errors |
| T-06-MEASURE-03 | Spoofing | a percentile reported over an incomplete sample set | high | mitigate | `Summary()` refuses empty, short, and non-positive sample sets with typed errors rather than returning a plausible number |
| T-06-MEASURE-04 | Elevation of Privilege | a noisy metric silently becoming a blocking gate | high | mitigate | `Demote` has exactly one `VerdictBlocking` return position, asserted structurally; only `recomputed_work` is gate-eligible |
| T-06-MEASURE-05 | Repudiation | drift between the shell sampling loop and the Go statistics | medium | mitigate | Exported sample-count and threshold constants pinned against the script in 06-15, the `TestPhase5CorpusBoundMatchesScript` precedent |
