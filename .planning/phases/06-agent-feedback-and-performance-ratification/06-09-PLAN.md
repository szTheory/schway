<objective>
Ratify budgets: a checked-in `qlt02_budget_manifest.json`, an executable audit that
cross-checks declared machines against live probe output, observation-only mode on an
undeclared machine, and the blocking rule wired into lane reporting.

Purpose: SC4 — declared-machine cold/warm distributions meet ratified budgets or identify a
specific blocking regression. The load-bearing framing: gate on the deterministic
machine-independent counter (`recomputed_work`), and report everything noisy honestly
alongside it rather than gating on it.
Output: the manifest, its audit, and populated `machine_id` / `gate_verdict` /
`cold_or_warm` lane fields.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `qlt02_budget_manifest.json` (embedded) -> gating | Checked in and reviewed like code; the JSON diff IS the review surface |
| live machine probe -> ratification decision | An unrecognized host must not be able to silently claim ratification |
| noisy wall-clock observation -> gate | The honesty seam D-06-22 defends |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-BUDGET-01 | Tampering | editing a ratified number until the run is green | high | mitigate | `AuditQLT02BudgetManifest` cross-checks declared machine IDs against live probe output; the JSON diff is the review surface; no code path writes the manifest |
| T-06-BUDGET-02 | Spoofing | an undeclared machine claiming ratified results | high | mitigate | `RatificationMode` returns `Ratified: false`; every lane's verdict becomes `not_ratified`; manifest access sits behind the branch, asserted structurally |
| T-06-BUDGET-03 | Elevation of Privilege | a noisy wall-clock signal becoming a blocking gate | high | mitigate | `EvaluateBudget` returns blocking only for `recomputed_work`; agreement with `measure.Demote` asserted independently |
| T-06-BUDGET-04 | Repudiation | a duplicate manifest row silently winning | medium | mitigate | `control:qlt02.duplicate_row` refuses the pair |
| T-06-BUDGET-05 | Information Disclosure | manifest rows encoding host identity | medium | mitigate | Rows key on `machine_id` only — a six-fact short hash with no hostname, serial, or MAC address (06-08) |
</threat_model>
