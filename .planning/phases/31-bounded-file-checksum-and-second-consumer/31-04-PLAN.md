<objective>
Prove APP-12's resource and size claims on native with fault injection:
- the owned buffer is released exactly once on success, oversize, allocation failure, a mid-read I/O error and a close failure (D-10);
- EINTR and short reads are retried (D-09);
- the size check is a bounded limit+1 read that never trusts the stat-reported size.

Each claim has an armed mutant that is observed to fail.

Purpose: these paths are unreachable from ordinary files. Without hooks, "release exactly once" and "never trusts st_size" would be unverified prose.

Output: the observer C file and the two native fault tests.
</objective>
