Harden the tracer frontend into a calm, formatter-owned, lossless editing surface
without enlarging Phase 1 semantics.

Purpose: Make generated and human-edited code stable under repeated AI loops,
malformed intermediate edits, parallel checks, and Git review before ownership
adds pressure to the grammar.

Output: `lang format`, comment-preserving CST formatting, bounded recovery, and
deterministic property/fuzz-seed tests.
</objective>

<flagged_assumptions>
- In Phase 1, `lang format FILE` writes canonical bytes to stdout and never
  mutates `FILE`; `lang format --check FILE` reports whether those bytes already
  match. This resolves repeat/concurrency ambiguity while preserving an atomic
  in-place formatter as a future additive feature.
- Comment preservation means byte-identical comment token text and stable
  source order. Attachment is deterministic to the following syntactic item,
  except end-of-line comments attach to the preceding item.
- Recovery is bounded to at most 20 diagnostics per file and at most the current
  declaration; reaching EOF is always progress.
- Property generators cover only the S1 grammar. Native fuzz mutation is a
  separate opt-in lane with an explicit time budget.
</flagged_assumptions>
