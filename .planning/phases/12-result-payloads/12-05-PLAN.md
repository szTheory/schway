Build criterion 2's anti-vacuity controls, so "layout has one meaning in the core
IR, the interpreter, and emitted C17" is a verified claim rather than an asserted
one — and record the niche clause's uninstantiability as a finding rather than a
skip.

Purpose: D-12-37 establishes that the obvious control is structurally
insufficient. A `_Static_assert` polices the struct declaration's
`sizeof`/`_Alignof`/`offsetof`; it can never police WHICH field a given match arm
actually reads. A `cgen` bug that reads the right-shaped struct at the wrong slot
for a correct tag leaves every `_Static_assert` green. Two controls, attacking
two different artifacts, are therefore required.

Output: a `PayloadLayoutMutationRunner` plus its frozen fixture, a reverted
production-hunk slot-swap mutation test with an unmutated companion run, and the
criterion-2 findings recorded in the debt register.

**Criterion 2's honest claim, stated precisely (D-12-26):** `interp` has no byte
layout at all — its value map has no size, alignment, or offset anywhere. "One
meaning in the core IR, the interpreter, and emitted C17" therefore CANNOT mean
byte-identical layout across all three. It means: the same alternative is live,
the same payload value is extracted, and the same events are emitted in the same
order — with layout-as-bytes a **C-only** obligation policed by
`_Static_assert`/`offsetof` pairs for internal self-consistency. A weaker claim
stated precisely is worth more than a stronger claim that cannot be true.
</objective>
