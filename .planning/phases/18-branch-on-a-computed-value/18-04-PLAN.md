## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Computed prefix -> checker match | An untrusted source binding must supply the scrutinee's checked place and type; the function parameter may have a different type. |
| Callee return -> caller match | Returned data must preserve type and place facts across the call contract. |
| Bare arm -> typed Result value | The selected alternative and edge-bound value place must match the declared return type before an OpReturn reads it. |
| Callee entry prefix -> interpreter arm dispatch | A called computed-match callee must initialize the match place before its arm is selected. |
| Compiler evidence -> comparator | Independent peers and engine results must not be inferred from one another. |
