## Planning decisions (delegated, not user-locked)

- Public syntax: `lang build SOURCE --output ARTIFACT`; `lang app run ARTIFACT -- INPUT`. `app run` accepts exactly one opaque argv token of at most 4096 bytes, including a token starting with `-` after `--`. This process transport can carry Phase 23's bounded caller-selected file path. Phase 22's generated U64 entry independently requires 1–20 ASCII decimal digits and a value at most `18446744073709551615`; leading zeroes are accepted and output is canonical unsigned decimal followed by one newline. Empty, signed, nondigit, extra, overlong, and overflowing input returns process exit 65 before the Lang body; wrong argument count returns 64. This is an input/entry rule, not resource admission.
- Build writes `ARTIFACT` plus adjacent `ARTIFACT.lang-build.json` after successful C17 compilation; the receipt records the executable digest, source and emitted-C digests, compiler executable/version/target, flags, declared runtime dependency `platform-c-runtime`, and an honest dependency-closure status. Stage in a private directory and publish after compile; incomplete closure is explicitly non-cacheable. The artifact path is outside the temporary build directory. Plan 22-02 extends this receipt with explicit local C inputs.
- The ordinary application route passes stdout/stderr through unchanged. Normal child exit maps to its numeric exit status; signal termination is reported by signal name and CLI status `128+signal`; timeout is status 124 and a launch/tool failure is 125, both with `lang app run:` diagnostics on stderr. A child may itself exit 124/125; the diagnostic and structured `RunOutcome` distinguish that case. Partial streams before an abnormal exit remain visible. Default timeout is 30 seconds. The parent does not parse application streams as compiler protocol. The existing `run --engine=native` remains a conformance path.
- Rate the public argv and receipt schema as `costly`: changing them later affects Phase 23 and checked-in examples, but the versioned receipt and typed entry codec avoid an on-disk migration. No new user decision checkpoint is needed because D-22-04 delegated these representations.
