<objective>
Close the phase's single highest-risk item — two independent analyses that today recognise only one of three terminators — and make the foreign declaration surface carry its alias facts rather than escape them.

Purpose: both `originvalidate` and `pathoracle` currently treat only a return as a terminator. Phase 4 introduces two more. If either walker misses one, the failure path becomes invisible to origin verification and to path enumeration while the optimization differential still passes, because that differential only compares paths the oracle enumerated. This reproduces exactly the defect class closed three times at the end of Phase 3.
Output: terminator-set-driven walks in both packages with a mutation-killed control, the foreign-origin refusal, published-origin validation wired into the check and run paths, honest work counting for the carried quadratic derivation, and a dated debt register for what is deliberately deferred.
</objective>
