<task type="checkpoint:decision">
  <name>Task 0: Ratify "cache artifacts, never verdicts"</name>
  <reversibility rating="one-way">D-06-06. Caching a verdict even once creates a false-proof vector that no later refactor can retroactively remove from already-published evidence. Once a green result that was never actually re-derived has shipped, it is in the record permanently.</reversibility>
  <decision>
    Confirm D-06-06 as written before any cache code exists (expected: yes, it is locked).

    The cache stores expensive intermediates ONLY — compiled binaries, instrumented
    (ASan/UBSan) binaries, per-mutant binaries. The checker, the five-axis comparator, and
    the sanitizer classifier ALWAYS re-run fresh against whatever binary — cached or newly
    built — is on disk this invocation. A cache hit therefore changes what is skipped and
    never what is asserted.

    Concretely, this constrains the package's API surface: no function in
    `internal/compiler/cache` may accept, store, or return a status, verdict, outcome,
    lane result, diagnostic, or boolean pass/fail. It stores opaque bytes plus a declared
    input record. That constraint is enforced by an exported-surface test in Task 1, not by
    convention.

    Also acknowledge D-06-13's recorded escapes, which are accepted, not closed:
    (1) undeclared environment — locale, `ulimit`, filesystem case-sensitivity;
    (2) a Clang change that does not alter its reported version string;
    (3) future nondeterministic codegen breaking the same-inputs-implies-same-artifact premise;
    (4) a hand-edited or partially-deleted cache directory being indistinguishable from a
    cold one, since there is no integrity check beyond content-hash lookup — consistent with
    the standing stance that SHA-256 is content identity, never proof. These are recorded in
    the escape register in 06-15, never hidden.
  </decision>
  <options>
    - **Accept as written (recommended):** artifacts only, enforced by an exported-surface test.
    - **Cache lane verdicts alongside artifacts:** faster still, and irreversibly creates the false-proof vector D-06-06 names. Rejected at discussion time.
    - **No cache at all:** honest but does not deliver DX-03's "reports reused cache inputs".
  </options>
  <recommendation>Accept as written. The API-surface enforcement in Task 1 is what makes it structural rather than aspirational.</recommendation>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cache directory on disk -> `Store.Get` | The cache directory is UNTRUSTED input: a user or another process can hand-edit or partially delete it |
| spawned `clang` subprocess -> `ProbeClangIdentity` | Untrusted, potentially unbounded stdout/stderr |
| declared input list -> key | The soundness seam: anything not declared is an escape by construction |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-CACHE-01 | Tampering | hand-edited or partially-deleted cache directory | high | accept | D-06-13 hole 4, explicitly recorded. No integrity check beyond content-hash lookup is claimed; `meta.json` input-list mismatch is treated as absent, which bounds but does not close it. Recorded in the 06-15 escape register, never hidden. |
| T-06-CACHE-02 | Denial of Service | unbounded `clang` probe stdout/stderr hanging key computation | high | mitigate | Reuse the shipped 64 KiB-plus-one bounded writer and 5-second deadline; typed truncation/timeout error, no second unbounded probe path |
| T-06-CACHE-03 | Spoofing | a Clang change that does not move its reported version string | high | mitigate | `clang_identity` is a probed digest over the binary's own bytes, not the version string; `TestClangDigestIsNotJustTheVersionString` pins it |
| T-06-CACHE-04 | Tampering | a verdict entering the cache | high | mitigate | `TestCacheExportedSurfaceStoresNoVerdict` + `TestCacheImportsStayIndependent` make artifacts-only structural |
| T-06-CACHE-05 | Denial of Service | unbounded artifact read from the cache directory | medium | mitigate | `io.LimitReader` at a declared byte cap plus strict JSON decode of `meta.json` |
| T-06-CACHE-06 | Tampering | undeclared environment (locale, ulimit, filesystem case-sensitivity) altering an artifact | medium | accept | D-06-13 hole 1, recorded in the escape register |
</threat_model>
