<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cache outcome -> assertion control flow | The critical seam: a cache result must not be able to steer whether an assertion runs |
| change-state file -> lane selection | An edited state file could otherwise cause a lane to be skipped and still render green |
| expanded evidence trace -> stdout | Must respect the shipped output bound |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-VERIFY-01 | Tampering | a cache hit skipping an assertion | high | mitigate | The assertion call sits outside the cache branch entirely, enforced by a `go/ast` structural test, not by convention |
| T-06-VERIFY-02 | Spoofing | a not-run lane rendering pass | high | mitigate | `addDeferredLane` hardcodes `StatusDeferred` and takes no status parameter; `TestDeferredLaneNeverRendersPass` asserts both the runtime and structural property |
| T-06-VERIFY-03 | Repudiation | a lane silently absent from the Result | high | mitigate | `TestEveryLiveLaneIsAccountedFor` requires selected-plus-deferred to equal `LiveLaneIDs()` exactly |
| T-06-VERIFY-04 | Denial of Service | unbounded expanded evidence trace | medium | mitigate | Existing 64 KiB-plus-one output bound plus `truncated:evidence.trace_bound` |
| T-06-VERIFY-05 | Tampering | cached binary bytes written to a temp path and executed | medium | accept | The cache directory is already an accepted escape (D-06-13 hole 4); execution of a cached compiler artifact is the same trust level as executing the freshly compiled one on the same host |
</threat_model>
