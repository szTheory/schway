<objective>
Ship the change-risk selection substrate: a checked-in `risk_lanes.json` declaration table
with an executable audit, conservative widening on anything unclassified, and a gitignored
local state file as the "changed" oracle.

Purpose: DX-03's "selects only evidence lanes relevant to changed risk". M001 has no call
graph, no modules, and no interprocedural edges to invalidate, so a rustc query graph or a
Bazel action graph would be enormous over-engineering (D-06-10).
Output: the registry, the selector, the audit, and the state file — all reporting values
only; the actual wiring into `verify` lands in 06-07 after the coordinated schema bump.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `risk_lanes.json` (embedded) -> selector | Checked into the repo and reviewed like code; trusted, but audited against the live lane set |
| change-state file on disk -> `LoadChangeState` | UNTRUSTED: a local file another process can edit or truncate |
| unclassified fixture kind -> lane selection | The fail-closed seam |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-RISK-01 | Tampering | edited change-state file causing a lane to be skipped | high | mitigate | Corrupt or unparseable state widens to all lanes; a state entry can only DEFER a lane whose declared-input hash matches, and a lane that was not run renders `deferred`, never `pass` |
| T-06-RISK-02 | Repudiation | a newly added lane silently escaping the declared table | high | mitigate | Bidirectional audit: `control:risklanes.undeclared_lane` fires for a live lane with no row |
| T-06-RISK-03 | Tampering | a stale row referencing a removed lane masking a real gap | medium | mitigate | `control:risklanes.stale_lane_reference` cross-checks against `LiveLaneIDs()` |
| T-06-RISK-04 | Denial of Service | unbounded state-file read | medium | mitigate | Bounded read at a declared cap plus strict JSON decode |
| T-06-RISK-05 | Information Disclosure | state file recording repository paths outside the cache dir | low | accept | Keys are fixture-relative names and lane IDs; no absolute host paths recorded |
</threat_model>
