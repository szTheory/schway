<objective>
Emit the phase's one optimizer-visible attribute — C `restrict` — on the
by-pointer parameter plan 05-01 created, bound to a proof `check` established and
`corevalidate` independently re-derived, and narrow (never delete)
`control:foreign.no_unproven_attributes` to enforce that binding.

Purpose: NAT-03's "false no-alias facts" mutation had no subject at all (D-04-32)
because Phase 4 emits zero optimizer-visible attributes. This plan creates the
honest subject. `restrict` is chosen deliberately as the older, better-understood
half of the alias lattice — Rust spent 2016-2021 fighting `noalias` on `&mut`
after real LLVM miscompiles, and C17 §6.7.3.1 `restrict` is exactly a promise
about the parameter object for the duration of that function's execution, which
is precisely what an exclusive loan already proves.

Output: a `restrict`-qualified by-pointer parameter in the Phase 5 golden, a
populated `emitted_attributes` list with justification bindings on the
`lang.foreign/0` sidecar, and a corevalidate re-derivation that refuses any
unbacked entry.
</objective>
