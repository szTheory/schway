<objective>
Build the first sanitizer lane in this repository: `lane:native-sanitize` — a
structurally isolated ASan+UBSan binary with harness-pinned options, a
`tool_missing` availability posture, and a stable classification tuple that is
the only thing allowed into content-bound evidence.

Purpose: three of NAT-03's mutations (retained-pointer lifetime, allocator
mismatch, use-after-free) are only detectable dynamically, and a plain `-O0`/`-O3`
run of any of them is UB rather than a guaranteed crash — the freed block is
often re-served intact and the program completes cleanly (D-05-10). ASan's
redzones plus its quarantine make the trap deterministic. This plan builds the
lane; plan 05-08 builds the fixtures that attack it.

Output: `internal/compiler/native/sanitize.go` with a distinct build+run path, a
`SanitizerReport` result type the comparator cannot accept, pinned option
constants, and a runtime-availability smoke probe.
</objective>
