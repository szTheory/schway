the thin end-to-end slice — source fixture, checker admission, core loan facts,
by-pointer C emission, native run — that proves the architecture before any
attribute, mutation runner, or lane is built on it.

pointer and runs correctly under the interpreter, `-O0` and `-O3`; a committed
golden for it; a hard byte-identity pin over Phase 1-4; and the `Alias` audit
closed in both independent layers.
