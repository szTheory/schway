<flagged_assumptions>
- S1 bounded commands emit one canonical JSON document. The protocol envelope
  reserves schema/kind/id fields so later long-running verification can add JSONL
  event streaming without replacing semantic records.
- `lang evidence FILE` emits a manifest; `lang evidence --validate MANIFEST FILE`
  validates it against freshly recomputed facts. Validation never trusts digests
  supplied by the manifest itself.
- Peak RSS measurement uses the best standard-library/host observation available
  on the declared Mac and is explicitly marked observational; missing measurement
  is `unavailable`, not zero.
- The manifest establishes content/tool/policy consistency, not an independent
  proof that source was lowered to the intended core. That escape remains named.
</flagged_assumptions>
