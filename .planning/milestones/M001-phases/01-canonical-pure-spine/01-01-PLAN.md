<objective>
Build the smallest real source-to-native compiler tracer for one closed nominal
ADT transformation.

Purpose: Replace further paper design with an executable seam that pressures the
syntax, typed core, checker, interpreter, C backend, host-tool boundary, and
diagnostic model together while all choices remain cheap to revise.

Output: A dependency-free Go compiler that checks and runs `toggle.lang` through
the interpreter and Clang at `-O0`/`-O3`, plus a seeded non-exhaustive control.
</objective>

<flagged_assumptions>
- Phase 1 source files are UTF-8; invalid UTF-8 is a stable lexical error.
- `lang check` and `lang run` are read-only and safe in concurrent processes
  because compilation state is request-local and native work uses fresh temp
  directories.
- Clang is an optional host tool: interpreter operation remains available when
  it is absent, while native requests fail with a distinct operational status.
- S1 functions have one named parameter and one expression body. This is a
  deliberate tracer boundary, not a permanent arity or grammar decision.
</flagged_assumptions>
