<objective>
Close EVD-03 and EVD-04: no claim or exclusion outlives its justification. Extend
the existing debt-register law with grade and witness columns under a closed
four-kind witness grammar, write the executed probes that back the day-one
register contents, enumerate every suppression surface in the module and require
each to cite a resolvable witness, and generate `.planning/UNREACHABLE-CLAIMS.md`
as a byte-compared view rather than a third authored store.

Purpose, and the argument this plan must lead with: a trigger written as a source
search over a file and line is the project's four-times-fired defect in a fifth
costume. When the searched symbol is refactored or renamed the search silently
stops matching and the guard goes green **for the wrong reason** — which is
exactly the escape of the fourth instance, where the guard watched the production
file while the stale marker lived in a test file and in an error string. The
industrial precedent that already solved this is the expected-to-fail test that is
*actually executed*, where an unexpected pass fails the suite. That is verbatim
EVD-04's "a guard fails when a cited gate has already closed". For the structurally
unreachable blame branch specifically, the right frame is deactivated code rather
than dead code: present, provably unexecutable in the current configuration,
justified by analysis that must be re-examined when the configuration changes —
which an executed probe forces and a phase-number citation cannot.

Output: a closed witness grammar, six executed probes, a module-wide suppression
enumerator with a three-seeded-fault non-inertness proof, and a generated
unreachable-claims view with fail-closed anti-decay guards.
</objective>
