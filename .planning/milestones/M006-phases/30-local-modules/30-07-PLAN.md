<objective>
Emit C for merged module programs using D-12 injective, length-prefixed names:
- entry functions are allocated first and keep today's names and ordinals, so no-import C stays byte-identical;
- imported functions are allocated second, in canonical (module, function) order, so import order never changes the C;
- every function is defined once.

Purpose: MOD-05 / SC4, the C half, together with the runnable gain's native lane.

Output: the two-pass allocation and its tests.
