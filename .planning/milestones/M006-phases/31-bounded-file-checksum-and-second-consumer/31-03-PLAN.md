<objective>
Prove that the third owner shape (D-06), including the D-16 optional trailing call, is enforced independently by every peer. Each peer gets an armed seeded fault per malformed neighbour and a named refusal for each source-level neighbour. cgen's D-17 stderr table must be derived from the program's own `FileError` alternatives.

Purpose: the repo law is that independent peers each refuse on their own. A matcher that admits a malformed trailing call and relies on a downstream peer is a silent soundness gap.

Output: one seeded-fault test file per peer package (test-only, unless a fault is not refused; see the action).
</objective>
