## Sampling Rate

- **After every task commit:** run the focused `-run` for each touched package. Also run the session meta set whenever `session.go`, a golden, a counted doc or a living marker changed.
- **After every plan wave:** run the session meta set, then `go test ./cmd/schway ./internal/compiler/check ./internal/compiler/interp ./internal/compiler/executionpeer ./internal/compiler/native ./internal/compiler/syntax -count=1`.
- **At freeze (before the user line):** require `SCHWAY_REQUIRE_NATIVE=1 go test ./... -count=1` green, a clean tree over the digest paths, and the armed freeze-gate controls rejecting.
- **Max feedback latency:** about 90 s for focused runs.
