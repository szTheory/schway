  <decision>
Adopt D-10-21's explicit `[]frame` heap stack with iterative dispatch as
`interp`'s call-stack model, instead of Go-native recursion.
  </decision>
  <reversibility>one-way</reversibility>
  <rationale>
This frame model is the shape Phase 11's five-axis comparator differentials
against. Changing it after Phase 11 begins moves every native baseline, so the
cost of reversal is not a refactor inside `interp` — it is regenerating
Phase 11's entire comparison substrate.

The decision is already LOCKED in 10-CONTEXT.md as D-10-21 and is not being
reopened here. This checkpoint exists because the reversibility rating is
`one-way`: confirm-and-proceed, so the irreversibility is acknowledged at the
moment it is incurred rather than discovered later.

Supporting fact (D-10-21): Go's stack exhaustion is a fatal runtime throw that
`recover()` cannot catch, so any design that recurses in Go is architecturally
incapable of satisfying SEM-08's "a named refusal, not a host stack overflow."
Recursion is disqualified, not merely dispreferred.
  </rationale>
