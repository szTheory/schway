<objective>
Make drop and cleanup obligations run in a DEFINED order across frames — on
normal return and on every nonlocal exit — and make that order observable as
ordered events rather than asserted against interpreter internals.

Purpose: SEM-09's second clause is narrow but NOT vacuous. Codename Lang has no
exceptions and no unwinding; `OpCall` is documented as never a terminator
(`core.go:559-564`). The only constructs that skip more than one frame are the
foreign process-root landing pad extended to N frames, and the SEM-08 depth
refusal. A plan that "satisfies" the second clause with a test exercising only
`OpReturn`/`OpFail` popping has proven the FIRST clause only — this plan must not
do that.

Output: cross-frame drain ordering in `interp` with its observation seam, the
`corevalidate`-checked callee-signature invariant that gives the order a second
independent knower, and the shipped statement of exactly how narrow clause 2 is.
</objective>

  <name>Decision: no event-schema change — frame attribution reuses FunctionID</name>
  <decision>
Attribute drop events to frames using the EXISTING `execution.Event.FunctionID`
field. Add no frame field, no depth field, and no new event kind to
`internal/compiler/execution/execution.go`.
  </decision>
  <reversibility>one-way</reversibility>
  <rationale>
`execution.Event`/`Schema0` is the contract Phase 11's five-axis comparator
consumes. A schema change AFTER Phase 11's baselines exist requires regenerating
every comparator baseline — the reversal cost is not local to this package.

The decision is already LOCKED in 10-CONTEXT.md as D-10-32 and is not being
reopened. This checkpoint exists because the reversibility rating is `one-way`.

The substantive reason: a `-O3 -flto` build can legitimately INLINE a callee, at
which point there is no runtime frame for native to reproduce a depth value from.
A depth field would manufacture guaranteed false divergences on the five-axis
comparator. `FunctionID` is a static, inlining-invariant source fact. Place IDs
are already function-namespaced, and `callgraph` refuses cycles so no function
calls itself — which makes `FunctionID` a SUFFICIENT attribution key for as long
as recursion stays refused. That dependency must be stated explicitly in the
code comment, because Phase 12's `Result` match arms could reopen it.
  </rationale>
  <options>
    - **Proceed (expected):** reuse `FunctionID`; leave `execution.go` untouched.
    - **Reopen:** only if the developer wishes to revisit a LOCKED decision. Halt and report.
  </options>
  <default>Proceed</default>
  <resume-signal>Type "proceed" to reuse FunctionID with no schema change, or describe the concern to reopen D-10-32.</resume-signal>

  <action>
Define and implement the cross-frame drain order (D-10-33).

On NORMAL RETURN (`OpReturn`/`OpFail`): the callee's frame must already be
drained of live resources before it pops. This is checked as a signature
invariant in Task 2, so the interpreter's job here is to emit the callee's drop
events, in the existing reverse-acquisition order, before the frame pops and
before any caller-frame drop event.

On the ABRUPT path: a strict LIFO flattening — innermost frame first,
reverse-acquisition order within each frame (the existing single-frame rule,
UNCHANGED), then outward. This composes for free because call frames are already
LIFO. The two abrupt paths that exist are the foreign process-root landing pad
(`interp.go:369`, today single-frame — extend it to N frames) and the SEM-08
depth refusal from plan 10-04. Both must drain.

Attribute every drop event with the existing `execution.Event.FunctionID`.
Add nothing to `execution.go`. In the comment, state the dependency explicitly:
`FunctionID` is a sufficient frame-attribution key FOR AS LONG AS recursion stays
refused by `callgraph`; Phase 12's `Result` match arms could reopen that.

Write the D-10-31 finding into the drain code's doc comment, as a finding, not a
footnote: `OpCall` is never a terminator; the language has no exceptions and no
unwinding; `OpFail` is an ordinary typed value propagated one boundary at a time,
not unwinding; therefore SEM-09's second clause covers exactly two constructs —
the foreign landing pad extended to N frames and the depth refusal. Say that a
test exercising only `OpReturn`/`OpFail` popping would prove clause 1 only.

Add the `frameDrainOrderForTest` observation seam (D-10-35): a nil-default
unexported seam, following `opCallGroupedArmForTest`'s established shape, that
flips drain order. EVERY ordering test in this plan asserts against
`interp.CanonicalBytes` / `execution.Equal` — NEVER against `frame`'s live-resource
fields or `live` map contents. Assert the seam produces divergent canonical bytes,
so the order is observed rather than asserted.

Determinism: run the determinism assertion at `-count=10`, because Go's
map-iteration randomization makes repeated runs genuinely informative
(D-10-26/D-10-57 clause 3).
