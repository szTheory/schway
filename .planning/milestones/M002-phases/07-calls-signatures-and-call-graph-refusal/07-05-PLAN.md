<objective>
Stage 1c. Implement SEM-06: a call is admitted only when the callee is
**callable ⊆ publishable** (D-04-03), consulted through a pre-body signature table
and nothing else, refused otherwise with a stable `core.*` code.

Purpose: two review findings meet here. **C-3** — `check.Program(ast.Program)`
receives no `core.Interface` and `session.Check` passes none, so the phase's
central claim (*"call admission consults only the callee's summary"*) was not
reachable through any planned API. **C-4** — the superseded plan enforced export
membership, a rule D-04-03 never stated. **D-07-34** resolves the first without
inventing a cross-module channel nothing could populate; `07-02`'s D-07-31
resolved the second, and this plan consumes that predicate rather than
re-deriving it.

Output: the pre-body signature pass and its immutable table; the SEM-06 refusal
with its `export_callee` repair explicitly rejected; the body-blindness control
with its seeded mutation; the A-normal-form relay/escort witness.

**D-07-34 — the pre-body signature pass.** Inside `check.Program`, before any
body admission runs, build an **immutable** signature table over all declared
functions **from signatures only**: for each declared function, its ID, name,
parameter contract, return contract, and its `Callable` bit. Body admission then
consults only that table. This satisfies *"admitted from the callee's published
signature summary alone, never from its body"* without inventing a cross-module
summary channel that nothing in Phase 07 can populate.

Three properties are load-bearing and each is asserted:
  - `check.Program`'s **public signature does not change**. No `core.Interface`
    parameter, no overload, no change at `session.Check`.
  - The table is built **before** the first body is admitted, and is **immutable**
    afterwards — a table a body pass can mutate is not a signature-only channel.
  - The table entry carries no reference to a `core.Function.Linear` or `Match`
    value, so the body is not reachable from admission even by following a
    pointer.

**Admission.** In the `"call"` arm, look the callee up in the table and refuse when
its `Callable` is false, emitting the code and constructor ratified at the
checkpoint. Never downgrade to a warning and never drop the call silently: this is
the phase's ASVS-V4-analogous access-control boundary, and `Callable`'s Go zero
value `false` makes absence the refusing case rather than the permitting one
(D-07-09), backed by `07-01`'s strict decoder.

**Fixture.** Author `testdata/phase07/call_uncallable_callee.lang`: module
`phase07.call_uncallable_callee`, whose callee is the
`clean_but_unpublishable.lang` function shape (checks clean on its own, fails
publication with `core.origin_omitted`, therefore `Callable == false`) and whose
caller calls it. Its leading `//` comment must state that this is SEM-06's
negative control, that the callee is refused because it is **not publishable**,
**not** because it is unexported, and that an unexported-callee fixture would test
a rule D-04-03 never stated (D-07-31b).
