| Boundary | Description |
|----------|-------------|
| oracle vs. binary | if the two engines resolve different entry functions or different inputs, the equivalence claim compares two different programs |
| cache → lane verdict | a lane that defers on unchanged declared inputs is asserting a verdict it did not re-derive |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
