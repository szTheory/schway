<objective>
Run the phase's riskiest assumption into the gate that can falsify it: prove on the
twin pair that blame lands where the program can actually be FIXED, not where the
violation was detected — and prove the three Set A classes reach `repaired` on
held-out fixtures rather than on the fixtures the repairs were derived from.

Purpose: ROADMAP criterion 3 and criterion 2. The re-check-clean oracle, not a
golden blame assertion, is what discriminates right blame from wrong blame: a
diagnostic that fires at the detection site looks correct in isolation and fails a
repair-then-re-check test immediately, because repairing the wrong function does not
make the program check clean. And a rule that always blames the callee passes the
first fixture by luck — which is why the mirror ships in the same set.

Output: the criterion-3 twin-pair regression with its detection-site mutation kill,
held-out integration across all three classes with exact outcome strings, the
extended non-contamination scan, and the mechanical proof that the driver's source
never changed.
</objective>
