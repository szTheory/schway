## Sampling Rate

- **After every task commit:** run the "packages" entry for the package touched, plus "quick".
- **After every plan wave:** run "packages", "quick" and `go vet` on the touched packages.
- **Before any planning-doc commit:** run "meta".
- **Before `/gsd-verify-work`:** hosted full and race suites green on both hosts at the final SHA (D-27.2-08), after explicit user approval for push and dispatch.
- **Max feedback latency:** 90 seconds locally. The hosted run is the phase gate.
